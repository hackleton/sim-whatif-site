# Sim.WhatIf

The website for [Sim.WhatIf](https://www.instagram.com/sim.whatif/): low-poly 3D what-if reels, built in code.

- `index.html` is the home page: two reels, a live "What if ___?" bar, and the 37.3 lakh views count.
- `how.html` explains how the videos are made.

It is a static site with no build step. To preview it, serve the folder with any static server, for example:

```bash
npx serve .
```
